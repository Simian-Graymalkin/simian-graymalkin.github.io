PROJECT INFORMATION

Privacy policy

Updated October 19, 2026. This policy describes the personal Simian Personal Mail Reader integration and this information website.

Data accessed and purpose

With the owner's authorization, the integration accesses account identity and connected calendar information, including calendar names and event details such as titles, dates, descriptions, locations, and attendees when supplied by the provider. It uses these details to answer scheduling questions and perform authorized calendar operations. Personal email workflows may process email data when the owner separately authorizes those services.

Processing and sharing

Calendar requests pass through the owner's private gateway. Requested information may be returned to Simian or Bubbles and processed by the assistant platform, including ChatGPT/OpenAI, to fulfill the owner's request. Google and Apple process requests to their respective services. This public website and its public source repository do not receive or contain the owner's calendar data, email data, or authentication credentials.

The integration is not an advertising service or a data marketplace. Google user data is used for the owner-directed functionality described here, not sold. Simian Personal Mail Reader's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

Connection credentials and configuration are stored on the owner's gateway host, separate from the public website. The gateway keeps operational logs for troubleshooting. Information returned to an assistant can remain in that platform's conversation history under its settings and policies. Revoking access stops future authorized requests but does not automatically remove previously saved conversations, logs, or source calendar records. The owner manages deletion of local records and assistant histories using the respective system controls.

Control over access

The owner can revoke the Google connection in Google Account connections and revoke the Apple app-specific password in Apple Account settings. The owner can also stop the gateway or remove stored credentials. Bubbles' bridge is read-only; the calendar gateway permits event creation and updates but blocks event deletion.

Website visitors and contact

This static site adds no analytics scripts, advertising, forms, or application cookies. GitHub Pages hosts it and may process technical request information under GitHub's privacy statement. For questions, contact the project owner. Never include credentials or private calendar/email content in public GitHub posts.
