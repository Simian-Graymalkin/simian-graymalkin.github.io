PERSONAL INTEGRATION · PROJECT INFORMATION

A connected assistant.
A private workspace.

Simian Personal Mail Reader is a personal assistant integration for its owner's connected accounts. Its calendar bridge helps Simian and Bubbles work with scheduling information.

What the integration does

The calendar gateway reads connected Google and iCloud calendars and supports creating and updating events for the owner. Bubbles accesses a read-only calendar bridge. The integration runs separately from this website.

The Google consent screen uses the name Simian Personal Mail Reader. This project supports personal email and calendar workflows; only the services authorized by the account owner are accessible.

Why Google access is requested

Google sign-in identifies the connected account. Calendar access lets the integration retrieve calendars and events and carry out authorized scheduling requests. Google may describe the Calendar permission broadly, including sharing and deletion; the current gateway blocks event deletion and Bubbles has read-only access.

Information only

This public website does not display calendars, email, credentials, or private bridge messages. It has no sign-in form and cannot connect a visitor's account. The integration is for the owner's personal use, not a public service.

Read the privacy policy and terms of use. For project inquiries, contact the project owner on GitHub. Do not post private account data in public issues.
